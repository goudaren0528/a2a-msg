**可信调用顺序与保证。**仅可信、同步、独占的离线 provision：`openImV2JournalDatabase({ path })` → `createImV2Journal({ db })` → 显式 `registerImV2JournalBinding(journal, db)` → 后续 consumer client `acquireImV2JournalOwner(journal)` / `assertHeld()` / `release()` → 调用方关闭 DB。`journal.js` 不自动注册；consumer client **尚未实现**，不得据此宣称激活。opener 直接检查调用方传入的最终路径分量；原路径、目录与文件 inode 身份在注册前、获取时和持有期间校验，移动或替换后不能将旧连接身份借给新文件；释放后旧 facade 重新获取也须通过身份检查。锁使用独立 sidecar 与独占 SQLite transaction，进程退出后由 SQLite 释放；不修复可疑 sidecar。此前“任意预打开 DB / 仅 canonical path”方案不能证明连接与原文件身份一致，已被此可信 opener 契约取代。
