## 设计口径（实现前定稿）

1. **每个 MCP 会话绑定一个 Agent 凭据**：`POST /mcp` 的 initialize 请求建立会话，session id 由
   SDK 随机生成；后续 `POST/GET/DELETE /mcp` 必须同时带 `Mcp-Session-Id` 和同一
   `Authorization: Bearer`。会话同时比对 `agentId` 与 `credentialId`，不同凭据不能复用会话。
2. **只走 HTTPS**：`/mcp` 不像 `/api/v1` 的 `local-test` 模式那样接受明文 HTTP；Bearer 永远不
   放进 URL、query、body 或日志。启动时使用中心已在用的 `direct-tls` 监听器。
3. **无状态以外的会话资源**：会话只在中心进程内存里保存 principal、传输和临时 journal；
   不保存明文 Bearer。空闲 30 分钟回收，最多 64 个会话；超限返回固定 `RATE_LIMITED`
   （429 + `Retry-After`）。
4. **工具集复用 `createImMcpAdapter`**：远程入口挂载共享适配器的 20 个网络工具；
   `im_v1_send_file` 只属于 stdio（它读宿主本地文件），远程入口不暴露，文档明确说明。
   适配器使用中心内部 transport 直接调用 `createImCenter` 已构造的 auth/ACL/messages/
   delivery/contacts 模块，不向自己回环发 HTTPS 请求。
5. **会话 journal 临时且本地**：每个会话用 0700 临时目录中的 SQLite journal，保留
   journal-before-ACK 语义；DELETE/过期/进程退出时关闭并清理。中心数据库本身仍是消息、
   lease 与 ACK 的唯一持久源。
6. **注册页只把令牌放在内存和当前 DOM**：`/join` 的“直接注册”使用页面自己解析出的
   `invite`，同源 `fetch POST /api/v1/enroll`；成功后显示一次 agentId、Claude Code HTTP
   命令与通用 JSON。令牌不写 localStorage/sessionStorage、不拼接进 URL、不写入页面源码；
   刷新后表单重置，旧令牌不再显示。失败只显示映射后的固定错误码，不回显服务端消息。
7. **保留 CLI 回退**：原来的接入提示词、CA 指纹校验与手工步骤不变；“直接注册”是额外路径。
8. **安全/限流**：`/mcp` 复用中心监听器的连接上限，增加每 IP 60 秒请求桶；Origin 若存在必须
   与中心 origin 一致；请求体上限复用 `limits.maxFileBodyBytes`；所有响应 `no-store`；
   无/错 Bearer 401，未知会话 404，方法不允许 405。
